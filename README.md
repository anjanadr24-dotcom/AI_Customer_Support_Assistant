# Support Intelligence - Live AI Customer Workspace

A high-performance, lightweight **Retrieval-Augmented Generation (RAG)** customer support desk system built using Python, Flask, and Bootstrap 5. This application allows support agents to upload unstructured company manuals dynamically and routes incoming user inquiries through a high-speed text isolation pipeline.

## 🚀 Key Features
* **Dynamic PDF Context Indexing:** Upload any standard operations manual or text-based PDF file to index matching data structures on-the-fly.
* **Intelligent Sentence RAG Extractor:** Automatically reads the user's intent to extract precise multi-sentence answers for specific questions (Business Hours, Return Rules, Cancellations).
* **Live Sentiment Analytics Panel:** Continuously processes incoming messages via a polarity scoring matrix to display real-time user mood counters.
* **Premium Interactive UI:** Built-in microphone processing, real-time pulsing typing animation delays, and fluid chat-box viewports.

---

## 🛠️ Tech Stack
* **Backend Framework:** Python, Flask
* **Data & Machine Learning:** Pandas, Scikit-Learn (TF-IDF Vectorization, Cosine Similarity)
* **Natural Language Processing:** TextBlob, PyPDF
* **Frontend UI Layout:** HTML5, CSS3, Bootstrap 5, jQuery
